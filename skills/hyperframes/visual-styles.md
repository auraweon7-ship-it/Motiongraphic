# Visual Styles — 비주얼 스타일 프리셋

## 1. Swiss Pulse (요제프 뮐러-브로크만)

정밀하고 클린한 스위스 디자인. SaaS, 데이터 시각화에 적합.

```yaml
palette:
  bg: "#F5F5F0"
  fg: "#1A1A1A"
  accent: "#E63946"
  muted: "#8D99AE"
typography:
  headline: "Helvetica Neue, 700, 72px"
  body: "Helvetica Neue, 300, 18px"
motion:
  ease: "power2.out"
  duration: "0.4s"
grid: "12-column, 16px gutter"
```

## 2. Velvet Standard (마시모 비녤리)

프리미엄, 럭셔리. 키노트, 기업 발표에 적합.

```yaml
palette:
  bg: "#0D0D0D"
  fg: "#F2F2F2"
  accent: "#C9A961"
  muted: "#4A4A4A"
typography:
  headline: "Bodoni, 700, 80px"
  body: "Garamond, 400, 20px"
motion:
  ease: "power3.inOut"
  duration: "0.6s"
```

## 3. Deconstructed (네빌 브로디)

산업적, raw한 느낌. 테크 런칭에 적합.

```yaml
palette:
  bg: "#1C1C1C"
  fg: "#E8E8E8"
  accent: "#FF4500"
  muted: "#666666"
typography:
  headline: "Impact, 900, 96px"
  body: "Courier, 400, 16px"
motion:
  ease: "power4.out"
  duration: "0.3s"
```

## 4. Maximalist Type (폴라 셰어)

대담하고 키네틱한 타이포. 대형 런칭, 이벤트 홍보에 적합.

```yaml
palette:
  bg: "#FFFFFF"
  fg: "#000000"
  accent: "#FF1493"
  secondary: "#00CED1"
typography:
  headline: "Anton, 900, 120px"
  body: "Inter, 400, 18px"
motion:
  ease: "elastic.out(1, 0.3)"
  duration: "0.5s"
```

## 5. Data Drift (레피크 아나돌)

미래지향적, 데이터 시각화. AI/ML 프로젝트에 적합.

```yaml
palette:
  bg: "#0A0A1A"
  fg: "#E0E0FF"
  accent: "#7B68EE"
  glow: "#00FFAA"
typography:
  headline: "Space Grotesk, 700, 64px"
  body: "IBM Plex Mono, 300, 16px"
motion:
  ease: "sine.inOut"
  duration: "0.8s"
```

## 6. Soft Signal (슈테판 자그마이스터)

따뜻하고 친밀한 느낌. 웰니스, 라이프스타일에 적합.

```yaml
palette:
  bg: "#FFF8F0"
  fg: "#2D2D2D"
  accent: "#FF8C69"
  muted: "#C9B99A"
typography:
  headline: "Playfair Display, 700, 56px"
  body: "Lato, 300, 18px"
motion:
  ease: "power1.inOut"
  duration: "0.7s"
```

## 7. Folk Frequency (에두아르도 테라사스)

문화적, 선명한 색감. 소비자 앱, 커뮤니티에 적합.

```yaml
palette:
  bg: "#FFFDE7"
  fg: "#1B1B1B"
  accent: "#E65100"
  secondary: "#00897B"
  tertiary: "#6A1B9A"
typography:
  headline: "Poppins, 800, 60px"
  body: "Nunito, 400, 18px"
motion:
  ease: "back.out(1.7)"
  duration: "0.5s"
```

## 8. Shadow Cut (한스 힐만)

어둡고 시네마틱. 드라마틱한 연출에 적합.

```yaml
palette:
  bg: "#0D0D0D"
  fg: "#D4D4D4"
  accent: "#DC143C"
  shadow: "#000000CC"
typography:
  headline: "Oswald, 700, 72px"
  body: "Source Sans Pro, 300, 18px"
motion:
  ease: "power3.out"
  duration: "0.5s"
```

## 스타일 선택 가이드

| 콘텐츠 유형 | 추천 스타일 |
|-------------|------------|
| SaaS / 데이터 | Swiss Pulse |
| 기업 발표 / 키노트 | Velvet Standard |
| 테크 런칭 | Deconstructed |
| 이벤트 / 캠페인 | Maximalist Type |
| AI / 미래 기술 | Data Drift |
| 웰니스 / 라이프스타일 | Soft Signal |
| 커뮤니티 / 소비자 앱 | Folk Frequency |
| 영화 / 드라마 | Shadow Cut |
